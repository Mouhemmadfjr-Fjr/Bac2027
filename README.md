# Bac2027

موقع تعليمي ثابت لأستاذ الفيزياء والكيمياء لمشاركة الموارد مع الطلاب.

## النشر والتحديث

1. أنشئ مستودعاً عاماً على GitHub باسم `Bac2027`.
2. ارفع الملفات إلى فرع `main`.
3. من **Settings → Pages** اختر **GitHub Actions** كمصدر النشر.
4. بعد أول تشغيل سيظهر رابط GitHub Pages الثابت للموقع.

بعد ذلك يكفي تعديل الملفات ورفع التغييرات إلى فرع `main`؛ سيعيد GitHub النشر تلقائياً على نفس الرابط. ويمكن ربط نطاق مخصص لاحقاً من إعدادات Pages دون تغيير الموقع.

## إضافة الملفات

الأقسام الستة داخل `files` هي:

- `files/physics/questions` — بنوك أسئلة الفيزياء
- `files/physics/summaries` — نوط وملخصات الفيزياء
- `files/physics/exams` — نماذج امتحانية للفيزياء
- `files/chemistry/questions` — بنوك أسئلة الكيمياء
- `files/chemistry/summaries` — نوط وملخصات الكيمياء
- `files/chemistry/exams` — نماذج امتحانية للكيمياء

ضع ملفًا أو أكثر داخل المجلد المناسب، ثم ارفع التغييرات إلى GitHub. أثناء النشر
يُعاد توليد `files/manifest.json` تلقائيًا، وتظهر الملفات تحت بعضها في القسم
المقابل دون تعديل `index.html`.

لتحديث الملفات عند فتح الموقع محليًا مباشرة من `index.html`، شغّل الأمر التالي
بعد إضافة أي ملف:

```powershell
node .\scripts\generate-manifest.mjs
```

أما عند استخدام GitHub Pages، فلا تحتاج إلى تشغيل الأمر يدويًا؛ إذ تنفذه مهمة
النشر تلقائيًا مع كل رفع جديد إلى فرع `main`.

لا يمكن لموقع ويب منع تنزيل المحتوى أو تصوير الشاشة بشكل مضمون، لذلك يفضل
مشاركة ملفات PDF بعلامة مائية أو استخدام منصة تعليمية تتطلب تسجيل الدخول للمحتوى الحساس.
